# Лицензии материалов ролика

## Музыка

Антонио Вивальди, «Времена года», концерт № 1 «Весна» (RV 269), 1-я часть Allegro — произведение в общественном достоянии.

В ролике используется **готовая свободная запись**, не синтез и не коммерческий лейбл:

- Исполнение: John Harrison (скрипка), Robert Turizziani (дирижёр), Wichita State University Chamber Players
- Запись: 6 февраля 2000, Wiedemann Recital Hall
- Источник: [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Vivaldi_-_Four_Seasons_1_Spring_mvt_1_Allegro_-_John_Harrison_violin.oga)
- Лицензия записи: [CC BY-SA](https://creativecommons.org/licenses/by-sa/4.0/) (версии 1.0–4.0, на выбор правообладателя)
- Локальная копия: `audio/source/vivaldi-spring.oga`

Атрибуция обязательна. Производный ролик распространяется на условиях CC BY-SA в части музыкальной дорожки.

## Изображения и интерфейс

Кадры панели и Telegram-макеты нарисованы скриптом `src/scenes.py` по фирменной палитре продукта. Скриншоты с секретами не используются. Демо-ФИО вымышлены.

Маскот ДИС — предоставленное автором изображение `assets/dis-fox.jpg` (низкополигональный лис). На кадрах лис вписывается целиком (contain), без обрезки ушей и лап.

## Шрифты

Системный стек Windows: Segoe UI / Segoe UI Bold (`C:\Windows\Fonts\segoeui.ttf`). Не загружаются с внешних CDN.

## Голос

Синтез: Microsoft Edge TTS, голос `ru-RU-DmitryNeural`. Запасной путь: установленный голос Windows. Условия использования облачного TTS определяет Microsoft; для локального показа демо это служебный синтез, не чужая актёрская запись.
